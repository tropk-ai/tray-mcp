Basta colar a URL abaixo em claude.ai → Settings → Connectors → Add custom connector. O Claude vai abrir a tela de autorização da Tray automaticamente — sem precisar gerar token manual.

https://tray-mcp.workers.dev/mcp

Como funciona

Quatro passos. Sem código, sem configuração de servidor. Funciona em minutos.

1 🛒

Instale o app

Encontre o Tray MCP na Loja de Aplicativos Tray e adicione à sua loja.

2 🔐

Autorize

Conexão via OAuth oficial Tray. Suas credenciais ficam seguras.

3 📋

Copie URL e token

Receba a URL MCP e o token de acesso direto no painel.

4 ⚡

Conecte no Claude

Cole em claude.ai → Settings → Connectors e pronto. Já pode conversar.

Conectar no Claude

Depois de instalar o app na Tray, você terá uma URL MCP e um token. Use eles nos clientes Claude:

claude.ai (Web)

Settings → Profile → Connectors → Add custom connector

  1. Name: Tray
  2. URL: https://tray-mcp.workers.dev/mcp
  3. Auth: Bearer <seu_token>

Claude Code (CLI)

Rode no terminal, dentro do seu projeto:

# adicione o servidor MCP
claude mcp add tray \
  --transport http \
  --url https://tray-mcp.workers.dev/mcp \
  --header "Authorization: Bearer <seu_token>"

Claude Desktop

Edite claude_desktop_config.json:

{
  "mcpServers": {
    "tray": {
      "url": "https://tray-mcp.workers.dev/mcp",
      "headers": {
        "Authorization": "Bearer <seu_token>"
      }
    }
  }
}
